#' Acquire Netflix What We Watched Reports
#'
#' This function will acquire and standardize all data for MP#01
#' from Netflix. Because Netflix hosts the data files behind a CDN, we
#' are accessing the release pages and automatically extracting links to the
#' relevant files (with CDN hash).
#'
#' After import, files are stacked vertically and some basic cleaning is
#' performed.
load_netflix_data <- function(){
  library(tidyverse)
  library(rvest)
  library(readxl)
  library(fs)
  
  data_dir <- path("data", "mp01")
  
  if(!dir_exists(data_dir)){
    dir_create(data_dir, showWarnings=FALSE, recurse=TRUE)
  }
  
  NETFLIX_URLS <- list(
    `2023H1` = "https://about.netflix.com/news/what-we-watched-a-netflix-engagement-report",
    `2023H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2023",
    `2024H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2024",
    `2024H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2024",
    `2025H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2025",
    `2025H2` = "https://about.netflix.com/news/what-we-watched-the-second-half-of-2025",
    `2026H1` = "https://about.netflix.com/news/what-we-watched-the-first-half-of-2026"
  )
  
  download_if_needed <- function(url, local){
    if(!file_exists(local)){
      download.file(url, local, quiet = TRUE, mode = "wb")
    }
  
    return(local)
  }
  
  NETFLIX_URLS |>
    map(read_html) |>
    map(html_element, xpath = "//a[contains(@href, '.xlsx')]") |>
    map_chr(html_attr, "href") |>
    enframe("period", "url") |>
   mutate(path = path(data_dir, paste0(period, ".xlsx")),
          path = map2(url, path, download_if_needed),
          data = map(path, read_excel, skip=3, na="*"),
          data = map(data, \(x) x |> mutate(`Release Date` = as.Date(`Release Date`)))) |>
    unnest(data) |>
    select(-url, -path) |>
    mutate(year=str_sub(period, 1, 4),
           half=str_sub(period, start=6),
           period_start = make_date(year, if_else(half==1, 1, 7), 1),
           period_end = make_date(year, if_else(half==1, 6, 12), if_else(half==1, 30, 31))) |>
    filter(!is.na(`Hours Viewed`)) |>
    mutate(live_event = !is.na(Runtime) & str_detect(Runtime, "\\d+:\\d+\\*"),
           clean_time = str_remove(Runtime, fixed("*")),
           Runtime = 60 * hour(hm(clean_time)) + minute(hm(clean_time))) |>
    select(-clean_time) |>
    mutate(Runtime = coalesce(Runtime, mean(Runtime, na.rm=TRUE)),
           .by=Title,
           Title = stringi::stri_trans_general(Title, "Latin-ASCII"),
           Title = str_remove(Title, " // .*"),
           Title = str_remove(Title, "[^[:ascii:]].*"),
           Title = str_trim(Title)) |>
    filter_out(Title == "") |>
    select(year,
           period,
           period_start,
           period_end,
           Title,
           -half,
           Runtime,
           Views,
           `Hours Viewed`,
           `Release Date`,
           `Available Globally?`,
           live_event)
}

NETFLIX_DATA <- load_netflix_data()

# Task 6.3: titles present in every period, ranked by their worst period.

# Task 6.4: classify titles. Live events are their own category; otherwise
# a title is a show if it has "Season", "Series", or "Limited" in the name
# or runs longer than 4 hours (240 minutes); everything else is a movie.
NETFLIX_DATA |>
  mutate(type = case_when(
    live_event ~ "Live Event",
    str_detect(title, "Season|Series|Limited") ~ "Show",
    coalesce(runtime > 240, FALSE) ~ "Show",
    TRUE ~ "Movie")) |>
  summarize(hours = sum(hours_viewed), .by = c(period, type)) |>
  mutate(share = hours / sum(hours), .by = period) |>

  arrange(period) |>

Subject: Netflix content strategy for 2027 and beyond

Netflix’s What We Watched reports from 2023-2026 revealed a meaningful path forward for Netflix in 2027 and onward. Global titles appear to be more efficient releases than regional titles. Another point is that returning seasons of series remain the most reliable way to claim the top spots. Even as new titles are still able to fill up the rest of the top ten, returning titles find their way frequently. Lastly, live events are holding their weight compared to the average pre-taped title, but the biggest live events remain much smaller than the biggest scripted shows. Live events have their place in Netflix’s ecosystem, but a more directed output could yield better results for the company.

Global Content

Global titles make up 38.2% of the catalog and account for 49.1% of all viewing hours. This means that they earn significantly more viewing per title than regional titles. Their share of total viewing hours declined from 57.2% in the second half of 2023 to 49.1% in the first half of 2026. We saw King the Land reach the number one spot despite being regional. Regional content is gaining momentum, but the gap is still significant. Some of the biggest successes like Squid Game and Money Heist show the strength of titles released with global reach. Breakout titles with room to grow spread quickly. Netflix should prioritize more of these titles since great titles are enjoyed worldwide and can be held back by regional locks.

Returning Franchises

Returning seasons claimed 5 of 7 number one spots, including the Bridgerton titles, Squid Game titles, and Wednesday titles. The only new titles to reach the number one spot were The Night Agent and King the Land. Returning seasons made up 40% of top ten slots, so new shows still occupy most of those slots. The number one title is also getting bigger over time, it went from 0.87% to 1.35%, so having a strong returning series is becoming more valuable as time goes. The Stranger Things series has 5,548,500,000 hours since they ran so this shows that these returning titles keep paying off for a substantial time. Squid Games was also a perfect example of this, a global breakout that held the number one spot for two consecutive periods and can continuously be built on as a returning franchise. For 2027 Netflix should continue with successful series but still keep launching enough new titles to create the next generation of these continuing seasons.

Live Events

Live events accounted for 0.5% of viewing hours in the first half of 2026. On average a live event drew 1,527,742 views while a pre-taped title drew 1,374,152. But when you compare the biggest live events with the biggest pre-taped titles, the gap is much bigger. The top pre-taped titles reach 9.4 times more views than the largest live events, 106,350,000 for pre-taped and 11,300,000 for live. Netflix should grow the category in a more focused way. The events already hold their weight against ordinary titles and clearly belong in the mix, but their lower ceiling argues for a focused route rather than a broad expansion.

Conclusion

Looking ahead, Netflix should build and keep emphasis on global titles as momentum has shown how massive a global title can reach. Also, Netflix should keep live events focused and targeted rather than expansive. Lastly, proven titles have shown that it is worth investing in returning seasons for them, but it is still important to keep the pipeline of new titles going so new opportunities for franchise building can arise. No single title can carry a substantial amount of viewing, so a wide catalog is important for Netflix. The data shows consumer interests for Netflix to cater to. It also shows areas where Netflix can reassess market goals and use resources wisely. Overall consumers are providing traceable feedback with glimpses and signs of what is working and what isn’t.
